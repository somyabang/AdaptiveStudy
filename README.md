# Your Adaptive Study Companion 📚🤖

### Plan Better. Focus Longer. Learn Smarter.

Your Adaptive Study Companion is a student-focused web application designed to make studying more organized, engaging, and productive. It brings study planning, focus sessions, reminders, progress tracking, and gamified motivation together in one place.

## 💡 Inspiration

Students often struggle with distractions, time management, and maintaining consistent study habits. We wanted to create a digital companion that helps students organize their learning, stay motivated, and make steady progress toward their academic goals.

## ✨ Features

- 📅 **Smart Study Planner** — Organize subjects, tasks, and study goals.
- ⏱️ **Focus Timer** — Manage study sessions and track time.
- 🔔 **Study Reminders** — Get reminders to return to planned study sessions.
- 🤖 **AI-Assisted Learning** — Support students with learning and doubt-solving features where implemented (DEMO).
- ⭐ **XP and Streaks** — Make consistent study habits more engaging.
- 📈 **Progress Tracking** — Review study activity and progress.
- 📝 **Quizzes and Flashcards** — Support revision and practice where implemented.
- 🎨 **Responsive Interface** — Designed for a simple, user-friendly experience.

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start exploring the available study features.

For the best experience, use a modern web browser.
